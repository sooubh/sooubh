## Featured Projects

### [Pactora](https://github.com/sooubh/pactora)
A 100% offline, privacy-first Flutter application for tracking personal promises, informal debts, and borrowed items. Built on a Zero Cloud philosophy — no accounts, no servers, no data harvesting. Available on Google Play Store.

`Flutter` `Dart` `Riverpod` `Isar DB` `Offline-First`

---

### [Care-AI](https://github.com/sooubh/Care-Ai)
An AI parenting companion for families supporting children with developmental and physical disabilities. Combines Gemini text and live voice assistance, therapy module libraries, doctor-parent coordination workflows, and Firebase-backed progress tracking.

`Flutter` `Dart` `Gemini API` `Firebase` `Provider`

---

### [KumbhSaathi](https://github.com/genaitics/kumbhSaathi)
A pilgrim safety application built for the Kumbh Mela. Features an AI voice assistant, SOS alerts, live GPS tracking, crowd heatmaps, and offline-capable operation designed for low-network environments.

`Flutter` `Dart` `Gemini AI` `Firebase` `OpenStreetMap`

---

### [ScrapKart AI](https://github.com/sooubh/ScrapKart-AI-Flutter)
A mobile application for AI-powered scrap material classification using YOLO and CNN models, with a dynamic pricing engine and real-time GPS-based collector dispatching.

`Flutter` `Dart` `Firebase` `Python ML` `YOLO`
